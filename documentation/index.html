02. Installation & Build Commands

Ensure Node.js 20.x or newer is installed on your workstation. Navigate into the industriq/ folder and run:

cd industriq
npm install
npm run dev

Your local development server starts at http://localhost:3000.

Production Build & Jamstack Static Export

# Standard Next.js SSR/SSG production build & server
npm run build
npm run start

# 100% Static Jamstack HTML Export (outputs to ./out)
npm run export

05. Editing Content & Adding Case Studies

Zero component JSX edits are required to swap demo company details, locations, machines, or case studies. Edit the corresponding TypeScript file in src/data/:

  • src/data/site.ts — Brand title, navigation, global campuses, KPI numbers, ticker bar.
  • src/data/solutions.ts — 6 production solutions & 5-phase manufacturing process workflow.
  • src/data/capabilities.ts — Machine fleet envelopes table & EN 10204 3.1 alloy database.
  • src/data/projects.ts — Case study entries & Zeiss CMM verification tables (automatically generates static /projects/[slug] routes).
  • src/data/insights.ts — Engineering articles & sections (automatically generates static /insights/[slug] routes).

06. Integrating the RFQ & Contact Form

The interactive RFQ form lives in src/components/forms/QuoteContactForm.tsx. It comes pre-built with client-side validation, accessible error annotations, loading transitions, and ticket confirmation feedback so static demos work out of the box.

To connect a live backend endpoint (such as Next.js Route Handlers, Resend, Formspree, or HubSpot), replace the simulated dispatch block inside handleSubmit with a standard fetch("/api/rfq", { method: "POST", body: JSON.stringify(form) }) request.

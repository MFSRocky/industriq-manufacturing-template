# Changelog — INDUSTRIQ Template

## [1.0.0] — 2026-11-21
### Added
- Initial commercial release built on Next.js 16.4, React 19, TypeScript 5.7, and Tailwind CSS v4.
- Complete 12-section Swiss-industrial brutalist homepage featuring asymmetric photographic compositions, telemetry marquee, animated tabular counters, interactive solution workbench, capability tabs, industry preview list, filterable case studies, 5-phase manufacturing process console, quality plaques, technology modules, insights grid, conversion CTA, and architectural footer.
- 10 full inner pages: About Us, Industries, Solutions, Capabilities (searchable equipment & alloy matrix), Projects (filterable/searchable catalog), Project Details (SSG with Zeiss CMM metrology tables), Quality & Certifications (interactive certificate tabs), Insights (searchable technical journal), Article Details (SSG with sticky TOC), and Contact (validated multi-spec RFQ form & interactive campus switcher).
- Global `⌘K` client-side engineering search modal across all 5 content domains.
- Self-contained art-directed industrial image suite in `public/images/`.
- Full Jamstack static export support (`npm run export`).
